# ToolNest — Fixed Professional Preview

This version has ALL CSS inline, so the design will render correctly even when `index.html` is opened directly for preview.

For REAL Google Login, the site must be deployed through a server and configured with a Google OAuth Client ID/redirect URI. Never put a Google Client Secret in frontend code.

Current included:
- Responsive professional UI
- Tools section
- Pricing
- Login modal
- Dashboard preview
- Invoice form preview

This is a frontend preview package; production authentication, database and payments require server configuration.
